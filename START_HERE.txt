🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

PROBLEM: "Python not found"
  SOLUTION: Install from https://python.org
           Make sure "Add to PATH" is checked

PROBLEM: Double-clicking setup.bat does nothing
  SOLUTION: Right-click → Open with → Command Prompt
           Or open Command Prompt, cd to folder, run setup.bat

PROBLEM: Takes 30+ seconds after upload
  SOLUTION: Normal! First detection downloads models
           Subsequent detections are 3-5 seconds

PROBLEM: Still only 4 elements detected
  SOLUTION: 1. Make sure app.py is running (check terminal)
           2. Try uploading again
           3. Check browser console (F12) for errors

PROBLEM: Port 5000 already in use
  SOLUTION: Edit app.py, change port 5000 to 5001
           Or close other app using port 5000

For more help, see: FLASK_SERVER_GUIDE.md

🎓 WHAT IS HAPPENING TECHNICALLY?
═══════════════════════════════════════════════════════════════════════════

Backend (Python):
  • Flask: Web server
  • EasyOCR: Text detection engine
  • OpenCV: Image preprocessing
  • NumPy: Numerical operations

Frontend (Browser):
  • HTML: Interface
  • JavaScript: Communication with server
  • Canvas: Display image

Processing Pipeline:
  1. Upload image → Sent to Python server
  2. Python receives → Stores in memory
  3. Preprocessing → CLAHE, bilateral filter, sharpen
  4. EasyOCR → Detects text in image
  5. Python processes → Groups text, extracts colors
  6. Results → Sent back to browser
  7. Browser → Displays text boxes
  8. User edits → Changes stored in browser
  9. Export → JSON with all data
