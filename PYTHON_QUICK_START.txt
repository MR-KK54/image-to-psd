Step 5: Run Server
  python app.py
  (Shows: "Access at: http://localhost:5000")

Step 6: Open Browser
  http://localhost:5000

⚙️ TECHNICAL DETAILS
═══════════════════════════════════════════════════════════════════════════

Backend: Python with Flask
  ├─ app.py: Main server with EasyOCR integration
  ├─ Libraries: Flask, OpenCV, NumPy, EasyOCR
  └─ Runs locally (no internet needed)

Image Processing Pipeline:
  1. Receive image from browser
  2. Grayscale conversion
  3. CLAHE (adaptive contrast enhancement)
  4. Bilateral filtering (denoise + edge preserve)
  5. Sharpening filter
  6. Otsu's threshold (binary conversion)
  7. EasyOCR detection
  8. Smart text grouping
  9. Color extraction
  10. Return results to browser

Detection Algorithm:
  • Confidence threshold: 15+ (very low - catches everything)
  • Line grouping: 0.3x height (strict - no merging)
  • Text grouping: Only if horizontally adjacent
  • Result: Each line = separate element

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

PROBLEM                 SOLUTION
─────────────────────────────────────────────────────────────
Python not found        Install from https://python.org
                        Make sure "Add to PATH" is checked

Port 5000 in use        Change port in app.py: port=5001
                        Or close other app using port 5000

ModuleNotFoundError     Run: pip install -r requirements.txt
                        Make sure virtual environment is active

Slow first run          Normal! EasyOCR downloads model (100MB)
(30+ seconds)           Subsequent runs are 3-5 seconds

Out of memory           Virtual environment didn't activate
                        Or image is too large (resize to <2000px)

Still only 4 elements   Make sure app.py is running
                        Check browser console (F12) for errors
                        Try uploading image again
